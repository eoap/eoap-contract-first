# Learning path

Follow the modules in order; each exercise verifies a real repository artifact.

- [00 — Understand Water Bodies](modules/00-waterbodies/README.md): Recognize the spectral and metadata processing graph.
- [01 — Design the contract](modules/01-design-the-contract/README.md): Design typed tool inputs and outputs before writing processing code.
- [02 — Derive the CLI](modules/02-derive-the-cli/README.md): Generate one Click group from all four tool contracts.
- [03 — Implement crop](modules/03-implement-crop/README.md): Select an EO common band and crop it in its raster CRS.
- [04 — Implement normalized difference](modules/04-implement-norm-diff/README.md): Implement ordered File[] inputs and validate raster grids.
- [05 — Implement Otsu](modules/05-implement-otsu/README.md): Classify finite NDWI and define invalid-pixel behavior.
- [06 — Implement STAC](modules/06-implement-stac/README.md): Publish the water mask as validated machine-readable product metadata.
- [07 — Compose the workflow](modules/07-compose-the-workflow/README.md): Connect the same tool contracts with scatter and typed dataflow.
- [08 — Containerize](modules/08-containerize/README.md): Represent execution environments as versioned dependencies.
- [09 — Run the application](modules/09-run-the-application/README.md): Verify tool outputs and end-to-end execution on compact data.
- [10 — Derive artifacts](modules/10-derive-artifacts/README.md): Generate genuine projections from the selected contract.
- [11 — Evolve and assure the contract](modules/11-assure-the-contract/README.md): Classify a public input change and its minimum SemVer release.
- [12 — Publish research software](modules/12-publish-research-software/README.md): Distinguish citation and CodeMeta from security evidence.
- [13 — Secure, promote and deploy](modules/13-secure-promote-deploy/README.md): Promote tested immutable application artifacts and execute them through ZOO.
