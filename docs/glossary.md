# Glossary

| Term | Meaning |
| --- | --- |
| CWL contract | Typed public processing API and execution declarations. |
| AOI | Region to crop, interpreted in the declared CRS. |
| COG | Cloud Optimized GeoTIFF with suitable internal layout. |
| NDWI | (green - nir) / (green + nir). |
| Otsu | Histogram-based threshold minimizing within-class variance. |
| STAC | Spatial, temporal and asset description of the result. |
| EOAP | Earth Observation Application Package. |
| SemVer | Release identity governed by interface compatibility. |
| Tag | Convenient reference that may be mutable. |
| Digest | Content identity of an OCI manifest or blob. |
| SBOM | Inventory of software components and relationships. |
| Attestation | Statement about an artifact, often with a verifiable signature. |
| Provenance | Evidence describing the process that produced an artifact. |
| Promotion | Decision to make a verified artifact eligible for deployment. |
