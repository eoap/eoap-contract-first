# Release and promotion mechanics

See [the supply-chain guide](../docs/supply-chain.md) for the verified lifecycle.

- `oras/package.sh`: local application/cwl OCI layout with generated annotations.
- `oras/publish.sh`: candidate registry publication and digest-addressed evidence association.
- `policy/scan.sh`: transparent HIGH/CRITICAL Trivy vulnerability gate.
- `examples/execute.json`: documented backend-native execution illustration with an explicit staging placeholder.

Real release inventory is generated by `task sbom:generate`. `task supply-chain:integration` inspects real built images through a temporary localhost registry; an actual historical bundle is included under reference/expected/sbom/local-example. No fabricated SBOM or digest is committed. Core CI checks contract/image identity declarations without authenticating to a registry.
